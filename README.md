# Virat Kohli — Cricket Career Performance Dashboard 🏏

An interactive Power BI dashboard designed to analyze and visualize Virat Kohli's cricket career performance across different years and opponents.

## 📊 Dashboard Overview

The dashboard provides a visual summary of Virat Kohli's batting performance, combining key career statistics with opponent-wise and year-wise analysis.

### Key Performance Metrics

| Metric | Value |
|---|---:|
| Total Matches | 431 |
| 100s | 69 |
| 50s | 110 |
| 30+ Scores | 232 |
| Batting Average | 47.70 |

## 📈 Analysis

The dashboard covers:

- **Runs Against Different Teams**
  - Australia
  - England
  - Sri Lanka
  - West Indies
  - South Africa

- **Matches Played Against Opponents**

- **Year-wise Batting Performance**
  - Analysis of yearly run-scoring trends
  - Interactive year selection

- **Career Overview**
  - ODI career start: 2008
  - T20 career start: 2010
  - Test career start: 2011

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Data Visualization
- Data Analysis
- Power Query

## 🎯 Objective

The objective of this project is to transform cricket performance data into an interactive and visually intuitive dashboard, making it easier to explore Virat Kohli's batting performance across different years and opponents.
